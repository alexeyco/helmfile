# AGENTS.md

Guidance for AI coding agents working in this repo.

## Documentation conventions

- All documentation is written in English
- `README.md` is for humans, this file is for agents
- Do not duplicate docs — cross-reference instead
- Human-first: anything useful to both humans and agents goes in `README.md`
- Bundled tool set lives in `README.md` — keep it there, do not repeat it here
- After changing any Markdown file, format it with Prettier: `npx prettier --write <file>.md`

## Repo purpose

Docker image for Kubernetes deploys in CI/CD — see `README.md`.

## Image design decisions (not recorded elsewhere)

- Final base image: `gcr.io/distroless/static-debian12` — CA certs needed by kubectl/helm TLS, so scratch was rejected; no shell, bundled tools must be static binaries
- Tool versions (kubectl/helm/helmfile/helm-diff/alpine): latest stable resolved at generation time from dl.k8s.io (kubectl), GitHub API (helm, helmfile, helm-diff) and the dl-cdn.alpinelinux.org directory index (alpine), no pinning
- Dockerfile template at `assets/Dockerfile.template`, embedded via the `assets` package (`assets/assets.go`) and rendered by `cmd/image` into the gitignored root `Dockerfile`
- Build & publish: `.github/workflows/docker.yml` builds the multi-arch image (daily 03:00 UTC + manual) and pushes it to GHCR as `latest` + the bundled helmfile version tag

## Commands

Always work with code through Makefile targets — never invoke `go` or
`golangci-lint` directly.

Run in this order when changing code: `make mod` → `make fmt` → `make lint` → `make test`.

- `make` — show help (all targets)
- `make build` — build binary `image` from `./cmd/image` into `./build` (gitignored)
- `make run` — run the app
- `make mock` — regenerate gomock mocks (`internal/fetcher/deps_test.go`, driven by `go:generate` in `deps.go`)
- Formatting and linting use golangci-lint v2+ (`golangci-lint fmt` / `golangci-lint run`); config: `.golangci.yml` (default linters)

## Current state

Module deps: `github.com/spf13/afero` (FS abstraction) and `go.uber.org/mock`
(as a `tool` dependency for mockgen). `assets` package embeds
`assets/Dockerfile.template`; `internal/versions.go` (package `internal`) holds
the shared `Versions` struct; `internal/fetcher` — `Fetcher` struct built via
`New(HTTPClient)` (interface in `deps.go`, mocks generated by `make mock`),
resolves all five tool versions in parallel; `internal/generate` — `Generator`
struct over `afero.Fs` with `Generate(v, path)` (tests use `afero.MemMapFs`);
`cmd/image` generator CLI (fetches versions and writes the root `Dockerfile`;
CI extracts the helmfile version tag from it); `make generate` target.
`.github/workflows/docker.yml` (daily 03:00 UTC + manual) builds the
multi-arch image and pushes it to GHCR as `latest` + helmfile version tag.
Generated root `Dockerfile` is gitignored.
